Task 3
Text Sizes (25px Outer, 10px Inner) with rem & em Comparison
Outer text (25px via 1.5625rem)
Inner text (10px via 0.625rem)
Outer text (25px via 1.5625em)
Inner text (10px via 0.4em of 25px)

The Difference: rem (Root EM) scales purely against the root HTML document font size (16px default), so both values remain static and immune to parent cascading. In contrast, em scales relative to the immediate parent's computed font size—hence the child requires 0.4em ($25\text{px} \times 0.4 = 10\text{px}$).
